- **UFMG / INCT Yeasts** · Biochemical Genetics Laboratory (since 2024)  
  Genomics of yeasts for biotechnology: genome and transcriptome analysis, gene annotation and phylogenetics.
- **CNPEM / LNBio** · Summer Research Program (2025)  
  Post-translational modifications in arboviruses (Oropouche virus glycosylation): viral purification, titration and mass spectrometry proteomics.
- **Neuroengineering research internship** (2026)  
  Behavioral data analysis with DeepLabCut and BORIS.
